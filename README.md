# CSV ML Compare

CSVを入れて、予測したい列とモデルを選ぶだけで、複数の機械学習モデルを同じ条件で学習させて比べるブラウザアプリです。
インストール不要。計算はすべてブラウザの中（[Pyodide](https://pyodide.org/) 上の scikit-learn）で行うので、データはどこにも送られません。

*A browser-only app: upload a CSV, pick a target column and several models, and compare them side by side. Runs scikit-learn in the browser via Pyodide; your data never leaves your machine.*

## できること

- CSVの読み込み（カンマ・タブ・セミコロン区切り、欠損値OK、文字の列は自動でカテゴリ扱い）
- 予測したい列を選ぶと、分類か回帰かを自動で判定（手動で切り替えも可）
- モデルを複数選んで一度に学習
  - 分類：ロジスティック回帰／決定木／ランダムフォレスト／勾配ブースティング／k近傍法／SVM／ナイーブベイズ
  - 回帰：線形回帰／リッジ回帰／決定木／ランダムフォレスト／勾配ブースティング／k近傍法／サポートベクター回帰
  - 比較の基準として「ベースライン」（何も学習しない当て方）を必ず一緒に出す
- 結果
  - 成績の表とグラフ（分類：正解率・バランス正解率・F1・AUC／回帰：R²・MAE・RMSE）
  - 交差検証（3分割・5分割）の平均と標準偏差
  - 効いている列（並べ替え重要度）
  - 混同行列（分類のみ）
  - テスト用の行の予測結果一覧と、CSVでのダウンロード

## 使い方

公開ページ（GitHub Pages）を開いて、CSVをドロップするだけです。初回は Python と scikit-learn の読み込みに 10〜30 秒ほどかかります。

手元で動かす場合は、ファイルを直接開くのではなく、簡単なサーバーを立ててください（Web Worker と `fetch` を使うため）。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 注意

- 目安は数万行・数十列まで。それ以上はブラウザが重くなります。SVM／サポートベクター回帰は 5,000 行を超えると自動で飛ばします。
- 成績は1回の分割での値です。大事な判断には交差検証の値も見てください。
- 「答えそのもの」が説明の列に入っていると、成績が不自然に高く出ます（リーク）。列の選び方を確認してください。
- 前処理は固定です（数値：中央値で補完＋標準化／文字：最頻値で補完＋One-Hot、上位30種類まで）。ハイパーパラメータの調整はしていません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面 |
| `worker.js` | Pyodide を読み込んで計算を担当（画面が固まらないよう別スレッド） |
| `ml_core.py` | 前処理・学習・評価（普通の Python からも使える） |
| `sample/sample_customers.csv` | サンプル（合成データ。実在の人や組織のデータではありません） |
| `tools/make_sample.py` | サンプルを作るスクリプト |
